# AURS Author Skill

[← Для разработчиков](../author-skill.ru.md) · [English](README.md)

**v0.7.0 · Early Beta · Frozen**  
Авторская методика и набор инструментов для создания, редактирования и проверки сцен `.aurs` в **Aureon** с помощью **Codex**.

> **Статус:** Early Beta, разработка приостановлена с 10 ноября 2026 года. Это не официальный релиз движка Aureon, не новый AURS API и не гарантия художественного результата. Техническая интеграция завершена, художественные испытания — частично.

**Целевая версия** — Aureon **0.24.5 v420** · **AURS API 1.1**.

## Возможности

| Блок | Что делает |
|---|---|
| **Creative Direction (A)** | Выбор процесса, художественного направления, ресурсного бюджета, роли музыки и интерпретации референсов |
| **Production Intelligence (B)** | Постановка кинематографичных миров: композиция, архитектура, детали, материалы, свет и проверка первого результата |
| **Motion & Music (C)** | Пространственное движение, автономная хореография, реакция на атаки/энергию/затухание музыки |
| **Multi-Keyframe (D)** | Методика построения **одного процедурного мира** по 2–4+ упорядоченным референсам, а не слайд-шоу |
| **Integration & Trials (E)** | Инструменты проверки, отчёты по независимым воротам качества и три тестовых брифа |
| **SDK / инструменты** | Справочник feature IDs и символов GLSL, preflight, упаковка `.aurs`, SDK parser, диагностика, diff, статический аудит |

Это **навык для автора/агента**, а не пользовательские настройки плеера. Он не добавляет поддержку новых форматов, 3D-реконструкцию из изображений или новые поля в AURS.

## Быстрый старт

1. Откройте папку `aureon-aurs-author/` и прочитайте `SKILL.md` и `CODEX_START_HERE_RU.md`.
2. Установите эту папку как Skill в вашем Codex **или** предоставьте её полный архив/рабочую папку и укажите путь к `SKILL.md`. Настройка каталога Skills зависит от версии вашего клиента Codex.
3. Если Skill зарегистрирован под именем `aureon-aurs-author`, начинайте запрос с `$aureon-aurs-author`.
4. Укажите художественную задачу, профиль и при необходимости референсы/музыку.
5. Получите один `.aurs` с подлинным `preview.png` (при поддержке SDK) и кратким отчётом. Видео и GIF по умолчанию не нужны.

Минимальный запрос:

```text
$aureon-aurs-author
Workflow: Production One-Shot
Art Direction: Cinematic / Environmental
Production Budget: Maximum
Music Direction: Ambient
References: None

Создай оригинальный кинематографичный мир с масштабной архитектурой,
сильной композицией, выразительными материалами и живой атмосферой.
Продумай мир до выбора рендерера. Сделай внутреннюю художественную проверку.
Выдай один .aurs со встроенным превью и кратким техническим отчётом.
Без MP4, GIF и контактных листов.
```

**Режим `Production One-Shot` допускает внутренние художественные исправления до одной выдачи.** `Strict One-Shot` сохраняет первый завершённый творческий build для независимой оценки, разрешая только отдельно зафиксированные технические исправления.

## Настройки профиля

Пять **независимых** осей задаются текстом в промпте (не в `manifest.json` и не в `scene.json`):

| Ось / ключ | Значения | Типичное применение |
|---|---|---|
| `workflow` | `adaptive` · `strict_one_shot` · `production_one_shot` · `iterative` | Свобода внутренних исправлений и число согласований |
| `art_direction` | `auto` · `cinematic_environmental` · `psychedelic_reactive` · `transformative_procedural` · `hybrid` | Художественная цель |
| `resource_intent` | `balanced` · `efficient` · `maximum` · `custom` | Распределение геометрии, текстур, проходов и вычислительного бюджета |
| `music_intent` | `adaptive` · `reactive_first` · `ambient` · `custom` | Роль музыки в пространственном поведении |
| `reference_mode` | `none` · `single` · `reference_set` · `multi_keyframe` | Как интерпретировать изображения |

Подробности и примеры: **[Полная таблица параметров](configuration.ru.md)**.

## Проверка качества и Early Beta

Согласно замороженному отчёту Stage E: **137/137 регрессионных тестов PASS** (документарные/структурные проверки, не визуальная оценка новых сцен).

Художественные испытания на момент фиксации:

- `PSY-01 Synaptic Maelstrom`: пакет создан, но **художественная приёмка не пройдена** — на полном цикле пользователь отметил недостаток динамики и психоделической выразительности.
- `CINE-01 Stormglass Shipyard`: **NOT_RUN**.
- `KEY-01 Eidolon Greenhouse`: **NOT_RUN**.

Тест SDK parser, запуск в Aureon, проверка с музыкальным файлом, GPU-замер и художественное принятие — **разные уровни доказательств**. Успешный тест Python не подтверждает графическое качество. Подробности: протокол.
