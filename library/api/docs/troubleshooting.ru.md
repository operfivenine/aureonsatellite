# Частые ошибки автора

[← API](../README.ru.md) · [English](troubleshooting.md)

| Симптом | Что проверить сначала |
| --- | --- |
| Unknown required feature | Точное имя и реестр выбранного renderer; исторические строки experimental нужно сохранить |
| Missing/unsupported fields | Правильный объект и профиль; нельзя объединять поля fullscreen и Hybrid |
| Импорт прошёл, сцена чёрная | Ошибки нативного GLSL, ресурсы, имена samplers и лимиты устройства; импорт не компилирует все GPU-программы |
| На Windows работает, на другой ОС нет ресурсов | Регистр имён, корень архива, относительные пути, GPU/драйвер целевой системы |
| В v1 нет реакции | Региональные attack-входы нейтральны; нужен предусмотренный отклик по уровням |
| Реакция неожиданно сильная | Повторное усиление в сигналах/материалах; проверьте каждый пользовательский регулятор отдельно |
| Движение скачет при смене музыки | Абсолютное время умножается на меняющуюся скорость; используйте интегрированную фазу |
| Вспышка после resize или переключения сцены | Старая history/feedback либо предположение о сохранении прежних GL-ресурсов |
| Произвольное поле заголовка трека отклонено | Hybrid использует host-атлас track_text, а не произвольные metadata/string uniforms |
| Stable-feature всё равно отклоняется | Неверный renderer, отсутствующие зависимости или недопустимое сочетание полей; stable не отменяет схемы |

См. [начало работы](getting-started.ru.md), [лимиты](limits-and-qa.ru.md) и [проверку перед выпуском](release-checklist.ru.md).
