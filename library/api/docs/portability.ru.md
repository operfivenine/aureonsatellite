# Переносимость и проверка платформ

[← API](../README.ru.md) · [English](portability.md)

Для Windows, Linux и macOS используйте единый декларативный контракт сцены. Соблюдайте точный регистр файлов, относительные пути с прямыми слешами, UTF-8 и объявленные типы ресурсов. Не зависите от `C:/`, обратных слешей, текущего каталога и конкретного пути установки.

Не встраивайте в AURS WinAPI, DWM, нативные DLL или Python. Меню, поведение окна, аудиобэкенды и адаптеры платформ принадлежат Aureon. Воспроизводимый дефект хоста описывайте отдельно, а не добавляйте платформенный код приложения в пакет.

Проверяйте реальную целевую ОС, архитектуру и драйвер GPU. Проверки: импорт, ресурсы, компиляция GLSL, качество/AA, fullscreen, камеры, переключение сцен, реакция на звук и перезапуск. Непроверенные платформы отмечайте честно. Поддержка feature в manifest не доказывает одинаковую работу любого шейдера на каждом драйвере.

Для сообщения об ошибке приложите ID/версию и хеш пакета, версию Aureon, ОС/архитектуру/GPU/драйвер, renderer, графические настройки, шаги и точный текст ошибки. Делитесь только нужными журналами; уберите личные пути к трекам и metadata, не требующиеся для воспроизведения проблемы.
