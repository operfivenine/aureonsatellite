# Стабильность и совместимость

[← API](../README.ru.md) · [English](stability.md)

**AURS API 1.1 · редакция 5 ноября 2026 · stable.** Ноябрьский реестр совместим с Aureon 0.23.0 · v385. Поддержанные возможности Mesh/Hybrid, материалов, геометрии, проходов, аудиотекстуры, камер и данных трека имеют стабильный статус.

`experimental` в `scene.hybrid_mesh.experimental.v1`, `scene.post_geometry.experimental.v1`, `aurs.geometry.experimental` и других существующих ID — историческая часть имени. Не удаляйте её и не изобретайте новые «stable»-алиасы: хост отклонит неизвестный обязательный ID. Стабильный статус не означает поддержку любой комбинации полей на любом GPU.

Версии профилей v1/v2, `format_version=1`, `engine.api_major=1` и `aurs.standard=1.1` сохранены. Готовые пакеты не требуют пересборки только из-за новой редакции документации. Схемы, лимиты и реализация не менялись; Python-модули хоста не являются внешним Python SDK.

Реестр содержит также сведения о проекциях AURP; настоящее руководство посвящено AURS-сценам. Не переносите контракт проекции в пакет сцены.
