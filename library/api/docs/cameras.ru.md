# Камеры и время

[← API](../README.ru.md) · [English](cameras.md)

Fullscreen v2 использует `behavior.camera`: shots, mode, transition/easing, ограничения,
presets и optional manual. Presets/manual требуют соответствующих features.
Uniforms камеры типизированы и перечислены в машинном справочнике. Авторский GLSL может
использовать собственную камеру, не объявляя неиспользуемый стандартный rig.

`camera.transition=0` разрешён для fullscreen v2 только при required
`scene.camera_cuts.experimental.v1`. Это прямое переключение подготовленных ракурсов;
обычный ненулевой переход сохраняет прежнее поведение. Здесь camera находится внутри behavior.

Mesh/Hybrid задают `camera.times`, `eyes`, `targets`, `fov`, `near`, `far`, `presets`.
Дополнительное `camera.clock` допускается только Hybrid с
`scene.mesh_camera_clock.experimental.v1`: значения route или scene.
Без поля используется прежний route. При scene Automatic использует общие часы мира;
после фиксированного ракурса возврат в Auto продолжает текущую фазу, а не начинает маршрут заново.
Скорость задаёт авторский camera.times; множитель Camera.speed не меняет общий ход мира.
Эти часы не привязаны к длине файла или seek; пауза музыки не останавливает самостоятельную жизнь мира.

Выбор камеры обслуживает хост. В полноэкранном режиме меню остаётся внутри панели сцен;
пакет не создаёт собственное окно меню и не определяет координаты кнопок приложения.
