# Лимиты, качество и проверка

[← API](../README.ru.md) · [English](limits-and-qa.md)

Общие лимиты: архив 800 МиБ, распакованное содержимое 1600 МиБ, один обычный ресурс 400 МиБ,
GLSL 12.5 МиБ. Большие mesh-ресурсы проходят отдельную профильную проверку.
Asset: до 128 карт, ось до 16384, до 1 ГиБ decoded texture budget, 32 material texture slots,
8 млн mesh vertices, 1024 batches, 256 материалов. Полные значения: [реестр возможностей](../reference/FEATURE_REGISTRY.json).

Поддержка 4K не означает автоматическую допустимость любой сцены: учитываются mipmaps,
history ping-pong, тени, отражения, scene snapshots и mesh buffers.
GL_MAX_TEXTURE_SIZE, GL_MAX_TEXTURE_IMAGE_UNITS и доступная память конкретного GPU
могут быть ниже разрешённых схемой. Снижение размера общего history buffer — авторский выбор.

`scene.graphics_advanced.v1` связывает объявленные graphics-переключатели с интерфейсом.
Общие resolution/antialiasing принадлежат хосту; авторские переключатели управляют
разрешёнными boolean quality defines, а не произвольной заменой shader source.
Уменьшенный framebuffer сцены и выходной MSAA framebuffer — разные цели.

Проверять: manifest/схему → настоящий импорт/обновление → low/medium/high и объявленный
extreme → 50/100% resolution и AA → Reactive v1/v2 → pause/seek/тишина → смену сцен →
фиксированные камеры/Automatic → F11 → повторное открытие приложения.
Все проверки автора проводить с отдельным профилем. Успешная проверка контейнера не доказывает
компиляцию GLSL на Intel/NVIDIA/AMD и не заменяет проверку памяти/кадров драйвером.

При смене сцены хост освобождает развёрнутые определения, не удерживая всю библиотеку
каталогом. Пакет не должен рассчитывать на сохранение своих GL-ресурсов после деактивации.
