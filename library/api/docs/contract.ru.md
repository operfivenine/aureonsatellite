# Контракт и совместимость

[← API](../README.ru.md) · [English](contract.md)

`manifest.json`: `format="aureon.theme"`, `package_type="scene"`, `format_version=1`,
`engine.api_major=1`, `entry="scene.json"`. Версия приложения 0.23.0 не означает API 2.0.
`scene.fullscreen_frag.v2`, Reactive v2 и `aurs.standard` 1.1 — независимые обозначения.

| Renderer | Область |
|---|---|
| scene.fullscreen_frag.v1 | Прежний один fragment shader и ограниченный граф сигналов |
| scene.fullscreen_frag.v2 | GLSL, расширенные сигналы, камера, текстуры, необязательный граф проходов |
| scene.mesh.experimental.v1 | Базовая геометрия, камера и качество |
| scene.hybrid_mesh.experimental.v1 | Общая геометрия/фон, материалы, анимация, проходы и opt-in расширения |

`features.required` и `capabilities.required` проверяются до установки; неизвестное обязательное
требование отклоняется. `optional` не включает отсутствующую реализацию автоматически.
Для новых возможностей можно указать `engine.min_aureon="0.23.0"`, но features всё равно обязательны.
Точный список по каждому renderer получен реальным manifest-валидатором в [реестр возможностей](../reference/FEATURE_REGISTRY.json).
Поддержка имени feature не отменяет зависимостей между полями сцены.

Пакет содержит декларативные JSON/GLSL и разрешённые ресурсы. Python, сеть, произвольные пути,
управление окном, медиаплеером или жизненным циклом OpenGL пакету не предоставляются.
Старые пакеты без новых opt-in сохраняют прежние ветки исполнения.
