# November edition and compatibility

[← API](../README.md) · [Русский](changes.ru.md)

Edition: 5 November 2026. `aurs.standard` remains 1.1; `format_version` and `engine.api_major` remain 1. Supported features have stable status. Existing technical identifiers and limits are unchanged. See [stability](stability.md).

Compared with the Aureon 0.22.3 / v367 contract, the current host supports expanded mesh assets, UV/tangent, texture/material bindings and resource budgets; GPU procedural instances and musical volleys; bounded volumetric lighting; feedback pass graphs and the published spectrum texture; Hybrid background inputs and read-only post_geometry color/depth; track palette and host-rendered title atlas; opt-in Hybrid history signals, volley travel clocks, scene-clock cameras and direct fullscreen-v2 camera cuts.

Regional attacks, Reactive controls, Advanced settings and older package behavior without new opt-ins are retained. These are host capabilities, not bundled artistic scenes or permission to execute host Python.
