# Проверка сцены перед выпуском

[← API](../README.ru.md) · [English](release-checklist.md)

| Проверка | Что записать |
| --- | --- |
| Идентичность | Собственный ID, повышенная версия из трёх чисел, локализованное имя с обязательным en |
| Контракт | Правильный renderer сцены, реально нужные features/capabilities, сохранённые технические ID |
| Контейнер | Manifest/scene JSON в корне, разрешённые ресурсы, точный регистр, UTF-8, без исполняемых вложений и выхода из путей |
| Импорт | Новый импорт и обновление в отдельном профиле; точный текст ошибки при отказе |
| Нативный рендер | Компиляция GLSL и первый кадр на каждой заявленной ОС/GPU |
| Графика | Low/Medium/High, заявленный Extreme, разрешение 50/100%, AA и переключатели Advanced |
| Аудио | Заявленные v1/v2; тишина, тихие/громкие участки, pause/resume, seek, быстрый Next и repeat |
| Камера | Auto и фиксированные ракурсы, переходы/cuts, возврат в Auto, fullscreen и resize |
| Ресурсы | Переключение на другую сцену и обратно, перезапуск, память после повторных переключений, восстановление истории |
| Данные трека | При использовании — смена палитры и атлас заголовка, пустые/длинные/Unicode названия |
| Поставка | Хеш итогового пакета, версия Aureon, ОС/архитектура/GPU, настройки, результаты и известные ограничения |

Не заменяйте непроверенную строку обещанием универсальной совместимости. Разделяйте приём контейнера, нативный рендер, замер производительности и художественный просмотр. Для выпуска пакета сцены не нужны пересборка плеера и автоматическая установка.
