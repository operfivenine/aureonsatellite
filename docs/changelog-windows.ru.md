# Aureon 0.24.5 · v420

[← Aureon](../README.ru.md) · [English](changelog-windows.md)

Накопительный список изменений с 0.23.0 · v385.

- Добавили режим выбора FPS и Split Grid для просмотра нескольких видео в одном окне. Улучшили управление плитками, масштабирование видео и восстановление окна при выходе из сетки.
- Обновили AURP. Добавили поддержку GPU-сцен, импорт таких проекций и восстановление выбранной проекции после перезапуска.
- Новые проекции выпуска — «Призматический купол» и Phosphor Veil.
- Расширили возможности Hybrid и исправили маску Post Geometry. Кривая анимации теперь использует время сцены.
- Обновили значки Windows для ярлыка, окна и трея.

## Известная проблема

В Split Grid остаётся баг таймлайна и визуальные помехи.
