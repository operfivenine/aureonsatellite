# Windows — Aureon 0.23.0 · v385

[← Aureon](../README.ru.md) · [English](changelog-windows.md)

Изменения по сравнению с 0.22.3 · v367:

- Улучшены остановка воспроизведения и завершение приложения.
- Расширены графические и аудиовходы пользовательских сцен; добавлены управление камерой, палитра трека и текст текущей композиции для совместимых пакетов.
- Улучшены освобождение ресурсов неактивных сцен, полноэкранное меню камеры и компоновка About.
- Reactive v2 выбран по умолчанию в новых профилях; сохранённый выбор v1/v2 остаётся прежним.
- Доработаны значки трея, работающего окна, мини-плеера и Scene Changer. Оригинальный логотип сохраняет обруч и звезду; иконка рабочего стола сохранена.
- Сохранены AURS API 1.1, 8 встроенных сцен и 4 проекции.

Проверки последней Windows-сборки: 324 модульных теста успешно, 2 пропуска; запуск и закрытие EXE на отдельном профиле; соответствие 195 модулей исходникам и проверка ресурсов установщика.
