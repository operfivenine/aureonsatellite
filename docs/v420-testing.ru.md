# Проверки Aureon v420

- **Windows x64, Linux x86_64 и macOS Intel в VM.** Проверены запуск и закрытие. На Windows отдельно проверен GPU-рендер Prismatic Dome.
- **MacBook Pro M4 Pro.** Подтверждён тест v385 через Rosetta. Нативный v420 на M4 Pro пока не проверен.
- Установка поверх старой версии пока не проверена.
