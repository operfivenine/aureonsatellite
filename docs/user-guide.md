# User guide

[← Aureon](../README.md) · [Русский](user-guide.ru.md)

**14 sections** about setting up and using Aureon, with recordings from the real interface.

**Drag and drop (DnD):** drag music from File Explorer into Aureon. For video, open the queue and drop the file **directly into it**. When music and video share the queue, the **Show videos first** button displays videos at the top while keeping the playback order unchanged.
