# Install a custom AURS scene

[← User guide](../user-guide.md) · [Русский](./19_Import_AURS_Scene.ru.md)

1. Import a .aurs package from Visuals.
2. Open Settings.
3. Choose Visuals.
4. Click Import scene.
5. Select your local media files.
6. Choose files, then click Open.
7. Aureon confirms the operation.
8. Open Idle Visual to find the imported scene.
9. Choose Amber Horizon.
10. Return to the player.
11. The imported scene now runs in Aureon.
