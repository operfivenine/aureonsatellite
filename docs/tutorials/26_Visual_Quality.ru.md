# Как настроить графику

[← Руководство](../user-guide.ru.md) · [English](./26_Visual_Quality.md)

Откройте **Settings → Visuals → Visual quality** и выберите качество.

- **Advanced** — ручная настройка разрешения рендера, детализации и эффектов.
- **Calibrate Auto** — проверка производительности текущей сцены на вашем устройстве и подбор качества для **Auto**. Дождитесь завершения и оставьте **Visual quality → Auto**. Ручные настройки Advanced сохраняются.
