# Настроить горячие клавиши

[← Руководство](../user-guide.ru.md) · [English](./23_Keyboard_Shortcuts.md)

Settings → Hotkeys → нажмите строку действия → введите сочетание. Правый клик по строке возвращает стандартное сочетание.
