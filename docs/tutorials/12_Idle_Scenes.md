# Choose the scene shown before playback

[← User guide](../user-guide.md) · [Русский](./12_Idle_Scenes.ru.md)

1. Open **Settings → Visuals**.
2. Open **Idle visual** and choose a scene.

The selected scene is shown before media playback, when no media is loaded.
