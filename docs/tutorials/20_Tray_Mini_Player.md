# Use Tray mode

[← User guide](../user-guide.md) · [Русский](./20_Tray_Mini_Player.ru.md)

## Tray and mini-player

1. Open **Settings → Tray** and enable **Tray mode**.
2. Enable **Minimize to tray** and minimize Aureon.
3. Right-click the Aureon tray icon to open the mini-player.
4. Use the mini-player to control playback or restore the main window.

![Tray mode and mini-player](../../assets/readme/tutorials/20_Tray_Mini_Player.gif)

## Projections

1. In **Settings → Tray → Projection**, choose a projection.
2. Open the tray mini-player and press its **Projection** button to start the selected projection.
3. Press the button again to stop it.

![Choose and start a projection](../../assets/readme/tutorials/21_Projections.gif)
