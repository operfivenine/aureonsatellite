# Add music to your queue

[← User guide](../user-guide.md) · [Русский](./01_Add_Music.ru.md)

1. Open the queue using the arrow on the right.
2. Click **+ FILES**, select your music files and click **Open**.
3. Select a track in the queue.

**Drag and drop (DnD):** you can also drag music files from File Explorer into Aureon. Drop video files directly into the queue; see [Open and play a video](15_Play_Video.md).
