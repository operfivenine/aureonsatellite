# Save and import local playlists

[← User guide](../user-guide.md) · [Русский](./22_Save_And_Import_Playlists.ru.md)

1. Save the queue as a local M3U8 playlist.
2. Open Queue.
3. Click SAVE to export the queue.
4. Select your local media files.
5. Choose a name, then click Save.
6. Aureon confirms the operation.
7. Your playlist file keeps the stored queue order.
8. An empty queue is ready for a saved playlist.
9. Click IMPORT and choose the saved playlist.
10. Choose files, then click Open.
11. The saved tracks are added back to the queue.
