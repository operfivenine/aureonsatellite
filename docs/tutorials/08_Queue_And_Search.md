# Use the queue and search

[← User guide](../user-guide.md) · [Русский](./08_Queue_And_Search.ru.md)

1. Open the queue to choose another track.
2. Open Queue.
3. Click Night Drive to play it.
4. Open queue search.
5. Type part of a track name.
6. Only matching tracks are shown.
7. Clear search to see the full queue.
