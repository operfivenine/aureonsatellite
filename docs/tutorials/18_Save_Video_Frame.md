# Save a video frame as PNG

[← User guide](../user-guide.md) · [Русский](./18_Save_Video_Frame.ru.md)

1. Enable Frame snapshot in Video settings.
2. Open Settings.
3. Choose Video.
4. Open Frame snapshot.
5. Enable Frame snapshot.
6. Return to the player.
7. Open the snapshot menu.
8. Choose Save frame.
9. Select your local media files.
10. Choose a name, then click Save.
11. A PNG of the video frame has been saved.
