# Choose a visual scene

[← User guide](../user-guide.md) · [Русский](./03_Choose_Scene.ru.md)

1. Click the scene name in the player to open **Scene Picker**.
2. Choose a scene.

**Scene Picker appears only when a track is in the queue.** You can also change the scene in **Settings → Visuals**.

To choose the background shown before playback, see [Choose the scene shown before playback](12_Idle_Scenes.md).
