# Добавить музыку в очередь

[← Руководство](../user-guide.ru.md) · [English](./01_Add_Music.md)

1. Откройте очередь стрелкой справа.
2. Нажмите **+ FILES**, выберите музыкальные файлы и нажмите **Открыть**.
3. Выберите трек в очереди.

**Перетаскивание (DnD):** музыку можно также перетащить из Проводника в Aureon. Видеофайлы перетаскивайте именно в очередь; см. [Воспроизвести видео](15_Play_Video.ru.md).
