# Воспроизвести видео

[← Руководство](../user-guide.ru.md) · [English](./15_Play_Video.md)

1. Откройте очередь и добавьте видео через **+ FILES** или перетащите файл из Проводника **именно в очередь**.
2. Выберите видео в очереди.

**DnD для видео работает при перетаскивании файла в очередь.**

Если в очереди есть музыка и видео, воспользуйтесь кнопкой **«Показать видео сверху»** на панели очереди. Она выводит видео в начало списка; порядок воспроизведения сохраняется.
