**Перетаскивание файлов (DnD):** музыку можно перетащить из Проводника в Aureon. Для видео откройте очередь и перетащите файл **именно в неё**. Если в очереди есть музыка и видео, кнопка **«Показать видео сверху»** выводит видео в начало списка, сохраняя порядок воспроизведения.
