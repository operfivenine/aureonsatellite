# Windows — Aureon 0.23.0 · v385

[← Aureon](../README.md) · [Русский](changelog-windows.ru.md)

Changes since 0.22.3 · v367:

- Improved playback shutdown and application exit handling.
- Expanded graphics and audio inputs for custom scenes, with camera controls, track palettes and now-playing text for compatible packages.
- Improved inactive-scene resource release, the fullscreen camera menu and About layout.
- Reactive v2 is the default for new profiles; saved v1/v2 choices are preserved.
- Refined tray, running-window, mini-player and Scene Changer icons. The original logo retains its ring and star; the desktop icon is preserved.
- AURS API 1.1, 8 built-in scenes and 4 projections are retained.

Latest Windows build checks: 324 unit tests passed, 2 skipped; private-profile EXE launch and exit; 195 bundled modules matched to source and installer resources verified.
