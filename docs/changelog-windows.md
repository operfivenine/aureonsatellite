# Aureon 0.24.5 · v420

[← Aureon](../README.md) · [Русский](changelog-windows.ru.md)

Cumulative changes since 0.23.0 · v385.

- Added FPS selection and Split Grid for viewing several videos in one window. Improved tile controls, video scaling and window restoration after leaving the grid.
- Updated AURP with GPU scenes, GPU projection import and restoration of the selected projection after restart.
- Added Prismatic Dome and Phosphor Veil.
- Expanded Hybrid support and fixed the Post Geometry mask. Animation curves now use scene time.
- Updated Windows shortcut, window and tray icons.

## Known issue

Split Grid still has a timeline bug and visual artifacts.
